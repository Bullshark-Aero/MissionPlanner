BSMP import rollback repair plan

Filename: bsmp-import-rollback-plan--202609061637--v1.0.0--missing-setting-journal.html

Status: Active. Created: 2026-09-06. Predecessor: none.

The Judicar 2600 v1.4.0 bundle contains valid QuickView fields whose desired state is absence. The importer records those removed keys as changed, then indexes the now-absent dictionary key while constructing its restart-verification journal. This raises KeyNotFoundException and rolls the transaction back.

  1. Extend the transaction journal to represent both expected values and expected absence.
  2. Make apply-time journal construction use TryGetValue, recording removed keys without indexing them.
  3. Verify both expected values and expected absence after restart, retaining compatibility with existing journals.
  4. Add regression coverage for a QuickView import that removes an existing setting and for restart verification of that absence.
  5. Run the focused tests, the wider BSA test set, Debug and Release builds, and an exact-package import check.
  6. Commit and push the repair to the existing task branch and PR. Package a new BSMP release using the enforced single-root-folder convention. Keep the unchanged Judicar aircraft bundle separate.

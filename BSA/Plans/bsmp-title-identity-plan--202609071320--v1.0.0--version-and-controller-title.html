BSMP title identity implementation plan

Status: approved for implementation · Version: v1.0.0 · Created: 2026-09-07 13:20 Europe/London

Outcome

Show an unambiguous BSMP, BSA firmware, upstream ArduPlane, flight-controller model, and controller UID identity in the application title after a vehicle connects.

Implementation

  1. Add one authoritative BSMP product-version value for the title.
  2. Add a small BSA firmware release catalog keyed by the firmware commit reported over MAVLink. The initial verified mapping is Judicar firmware commit 98cc2c8f: BSA ArduPlane V1.4.1, based on ArduPlane V4.7.0.
  3. Format the connected title from the catalog, controller model, and canonical MAVLink UID. If firmware is not catalogued, retain the firmware identity reported by the aircraft and do not invent a BSA version.
  4. Keep the disconnected title limited to the BSMP product identity.
  5. Add focused tests for known firmware, unknown firmware, UID normalization, missing fields, and disconnected state.

Verification and delivery

  1. Run focused tests and a Release build on the supported Windows build environment.
  2. Inspect the resulting title using representative Judicar and unknown-firmware inputs.
  3. Commit on platform/mission-planner/identity-title, push that task branch, and open a pull request to the default branch.

Rollback

Revert the feature commit. No vehicle parameters, firmware, hardware, or persisted aircraft configuration are changed.
